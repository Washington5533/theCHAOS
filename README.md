# 混沌摆跑酷 (Chaos Pendulum Parkour)

> C++ 课程项目 | 大连理工大学软件学院 | 面向对象方法程序设计与实践

基于混沌双摆物理系统的单人动作跑酷游戏。角色在双摆杆和球面上行走，借助混沌运动的动量甩出，配合钩锁在杆与摆锤间穿梭，躲避尖刺、触碰得分平台获取分数。

## 核心玩法

```
步行面上观察摆向 → 选时机脱手 → 混沌运动甩出 →
空中钩锁调整方向 → 落回结构面 → 触碰平台得分 → ...
```

角色在双摆的四段步行面（L1杆 → m1球面 → L2杆 → m2球面）上行走。由于双摆的混沌特性，轨迹不可预测——玩家需要借助物理直觉判断跳跃与钩锁时机。

## 操作说明

| 按键 | 功能 |
|------|------|
| **A / D** | 在步行面上左右移动 |
| **W** | 跳跃脱手（继承脚下速度）/ 钩锁中打断松钩 |
| **鼠标左键** | 向光标方向发射钩锁（最大射程 320px） |
| **Space** | 暂停 / 恢复 |
| **R** | 全局重置（摆+角色+场景） |
| **Q / E** | 重力倍率 -0.1x / +0.1x（范围 0.1x~3.0x） |
| **F** | 球捕获模式切换（仅杆端 / 全程距离） |
| **1~5** | 切换双摆初始预设角度 |
| **Esc** | 退出 |

## 物理系统

### 双摆

基于拉格朗日力学推导角加速度方程，使用 **Symplectic Euler** 积分器（32子步/帧），能量守恒误差 < 0.1%。

| 参数 | 值 | 说明 |
|------|-----|------|
| L₁ / L₂ | 225 / 180 px | 杆长 |
| m₁ / m₂ | 2.0 / 1.5 | 质量 |
| R₁ / R₂ | 50 / 40 px | 球半径 |
| g | 600 px/s² | 重力（可调） |

### 步行面四段系统

| 段 | 说明 | 吸附方式 |
|----|------|---------|
| L1_ROD | L1 杆上方侧（偏移12px） | 点到线段距离 |
| M1_BALL | m1 关节球面弧 | 点到球心距离 - R₁ |
| L2_ROD | L2 杆上方侧 | 点到线段距离 |
| M2_BALL | m2 末端球面弧 | 点到球心距离 - R₂ |

### 脱落机制

| 表面 | 速度甩出 | 角度脱落 | 杆面下滑 |
|------|---------|---------|---------|
| 杆 (L1_ROD / L2_ROD) | ❌ | ❌ | ✅ 倾角 >30° |
| 球 (M1_BALL / M2_BALL) | ✅ ω×R > 200 px/s | ✅ 边界 t<0.01 或 t>0.99 | ❌ |

## 角色状态机

```
                  (杆面下滑/球面脱落)
                         ▼
┌─────────┐  W键    ┌───────┐  钩锁命中  ┌──────────┐
│ ON_ROD  │ ──────→ │ FLY   │ ────────→ │  HOOKED  │
│ (步行面) │ ←────── │ (自由) │ ←─────── │ (弹性绳) │
└──────────┘ snap回面 └───────┘  W打断跳跃 └──────────┘
     │                   │                      │
     └───────┬───────────┴──────────┬───────────┘
             │      碰刺/出屏       │
             ▼                      ▼
       ┌──────────────────────────────────┐
       │              DEAD                │
       │   (粒子爆发 → 0.5s → 自动重置)    │
       └──────────────────────────────────┘
```

### 钩锁系统

- **2发充能**，独立冷却 0.5s（SDL2）/ 1.0s（EasyX）
- 射线检测：优先命中线段（杆）或圆（球），取最近者
- 弹性绳物理：K=7.0，自然绳长 8px，最大拉伸 1.4x
- 钩点随摆锤实时运动
- W 键可打断钩锁并附加跳跃初速度 400 px/s
