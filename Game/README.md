# Chaos Pendulum — 混沌摆钩爪游戏

> C++ + SDL2 | 单人 | 单场景跑酷 | 混沌双摆 + 钩锁动作

---

## 游戏简介

你在一个混沌双摆的杆上自由行走，利用双摆的物理动量把自己甩向目标，配合钩锁在杆和摆锤之间来回穿梭。场景中散布尖刺障碍和得分平台——碰到尖刺即死，触碰平台得分。

**核心玩法循环：**

```
结构面上行走观察摆向 → 选时机脱手 → 被高速甩出 →
空中钩杆/球调整方向 → 落回结构面继续走 → 触碰得分平台 → ...
```

---

## 操作说明

| 按键 | 功能 |
|------|------|
| **W** | 跳跃 / 脱手（ON_ROD→FLY），钩锁中按W可松钩+上跳 |
| **A / D** | 在步行面上左右移动 |
| **鼠标左键** | 发射钩锁（向鼠标方向，最大射程 320px） |
| **Space** | 暂停 / 恢复（显示能量核心风格暂停菜单） |
| **R** | 重置全局状态（钟摆+角色+场景） |
| **Q / E** | 调节重力倍率（-0.1x / +0.1x，范围 0.1x~3.0x） |
| **F** | 切换球捕获模式（全程距离 / 仅杆端） |
| **1~5** | 切换钟摆初始预设角度 |
| **ESC** | 退出游戏 |

## 物理系统

### 双摆参数

| 参数 | 值 | 说明 |
|------|-----|------|
| L₁ | 225 px | 第一杆长 |
| L₂ | 180 px | 第二杆长 |
| m₁ | 2.0 | 关节球质量 |
| m₂ | 1.5 | 末端球质量 |
| g | 600 px/s² | 重力加速度 (可调) |
| R₁ | 50 px | 关节球半径 |
| R₂ | 40 px | 末端球半径 |
| 子步数 | 32 | 每帧物理步进次数 |

### 积分器

Symplectic Euler：先更新角速度 (ω += α·dt)，再更新角度 (θ += ω·dt)。能量守恒 < 0.1%。

### 角度标准化

每步将角度折叠到 [-π, π]，防止浮点溢出。

## 角色状态机

```
                    ┌─────────────────────────────────────────┐
                    │  (杆面: 倾斜>30°时被动下滑)               │
                    │  (球面: 速度>200px/s甩出 / 角度边界脱落)   │
                    ▼                                         │
┌─────────┐  W键    ┌───────┐  钩锁(命中任意表面) ┌──────────┐
│ ON_ROD  │ ──────→ │ FLY   │ ──────────────────→ │  HOOKED  │
│ (步行面) │ ←────── │ (自由) │ ←────────────────── │ (弹性绳) │
└──────────┘ 落回面  └───────┘   W键跳跃打断        └──────────┘
     │                   │                            │
     │  出屏/碰刺         │  出屏/碰刺                   │  出屏/碰刺
     └────────┬──────────┴─────────────┬───────────────┘
              │                        │
              ▼                        ▼
        ┌──────────────────────────────────┐
        │              DEAD                │
        │      (粒子爆发 → 0.5s → 重置)     │
        └──────────────────────────────────┘
```

### 步行面四段系统

| 段 | 说明 | t=0 | t=1 |
|----|------|-----|-----|
| L1_ROD | L1 杆上方侧 (偏移12px) | 支点端 | 关节端 |
| M1_BALL | m1 关节球面弧 | 接L1侧 | 接L2侧 |
| L2_ROD | L2 杆上方侧 | 关节端 | 末端端 |
| M2_BALL | m2 末端球面弧 | 接L2侧 | 球正上方 |

四段互不连通，切换表面只能通过：钩锁命中 / FLY中snap回面 / 跳跃。

## 得分系统

| 得分方式 | 分值 | 触发条件 |
|---------|------|---------|
| 触碰得分平台 | +1 | 角色AABB与平台碰撞 |
| 存活15秒 | +1 | 非死亡状态下每存活15秒 |
| 死亡 | -1 | 死亡重置后自动扣除 |

得分时触发：球体白色脉冲扩张 + 角色离子迸溅特效。

## 视觉特效系统

### 球体渲染 (CP8)

| 特效 | 描述 |
|------|------|
| 3D 立体光照 | 预计算纹理 + Blinn-Phong 漫反射/镜面高光 |
| 速度响应变色 | 冷→热→白热两段插值，实时 `SDL_SetTextureColorMod` |
| 心跳脉动 | ±1.5% 半径 sin 缩放 |
| Bloom 外发光 | 3层半透明光晕，动能驱动强度 |
| 运动残影 | 12帧环形缓冲，表面速度>150px/s时显示 |
| 轨道火花 | |ω|>3 rad/s 时球面喷射切向粒子 |
| 碰撞波纹 | 钩中球时白色圆环扩散 |

### 交互反馈

| 反馈 | 触发 | 视觉 | 衰减 |
|------|------|------|------|
| 踩上脉冲 | warpTo 切到球面 | 球半径+4px | 0.2s |
| 钩中闪光 | hook 命中球面 | 高光扩大+白色波纹环 | 0.15s |
| 跳离挤压 | jump 从球面跳离 | Y压缩8%+X拉伸 | 0.3s |
| 甩出爆发 | 速度甩出/角度脱落 | 边缘白色光晕 | 0.2s |
| 死亡红爆 | 角色死亡 | 球变红+喷射红色粒子 | 0.3s |
| 得分脉冲 | 得分事件 | 球扩张+3px+白闪 | 0.15s |

### 尖刺视觉

- 暗色基座 + 三角锥阵列（扫描线填充）
- 尖端脉冲闪烁（sin 驱动，每锥相位偏移）
- 支持正置（尖端向上）和倒置（尖端向下）

### 得分平台视觉

- 发光悬浮球：逐行扫描渐变（底部深蓝→顶部亮青）
- 外层光晕 + 高光点
- 浮动动画（sin 驱动，每个平台相位不同）

### 角色视觉 (能量核心体)

| 状态 | 颜色 | 形状 |
|------|------|------|
| ON_ROD (杆上) | 绿色 | 菱形轮廓 + 中心高光 + 呼吸光晕 |
| FLY (飞行) | 黄色 | 同上 |
| HOOKED (钩锁) | 蓝色 | 同上 |
| DEAD (死亡) | 红色闪烁 | 粒子爆发 |

### 钩锁绳视觉

- HOOKED 状态下黄色能量绳
- 发光能量残影（仅拉伸时显示）
- 火花粒子沿绳飞散

### HUD

- 左上角：钩锁充能格（2格，冷却进度从底部填充）
- 左侧：M1/M2 表面线速度 + 角色速度（绿→红渐变）

### 暂停菜单

- 能量核心风格：菱形主体 + 呼吸光晕 + 中心高光
- PAUSED 标题 + SCORE/TIME 状态信息
- 键位提示（字母蓝色 + 描述灰色分色渲染）

### 像素字体系统

- 3×5 点阵数字 (0-9) + 字母 (A-Z)
- 支持任意 dot 缩放
- 用于 HUD、暂停菜单、速度显示

## 关卡系统

### 场景生成

每次 R 键重置或死亡后随机生成：

| 元素 | 数量 | 位置范围 |
|------|------|---------|
| 尖刺 | 2块 | 70%概率：2块下部(y:550~870)；30%概率：1顶部+1下部 |
| 得分平台 | 2个 | A:上部(y:120~370)；B:中部(y:370~550) |

得分平台被触碰后自动刷新到新随机位置。

## 已知问题

1. **球面跳跃反馈不足**：球速峰值 2000+ px/s 时，JUMP_BOOST(400) 视觉上不可感知
2. **球面角度脱落边界敏感**：安全区 t∈[0.01, 0.99]，极端摆动下可能频繁震荡
3. **性能积累**：32 substep/帧全用 double 精度，可优化为 float
