## 一、球面跳跃反馈不足

### 现象

站在球面上按 W 跳跃，当球体高速运动时（ω₁/ω₂ 峰值 5~8 rad/s，表面速度 2000+ px/s），角色虽然**确实脱离了球面**（相对速度 200 px/s），但视觉上角色和球肩并肩高速飞行，看不出"跳"的动作。

### 速度链

```
jump():
  vel_ = footVel(p, pivot)   // 继承球面速度, 峰值 ~2000+ px/s
  vel_.y -= JUMP_BOOST        // -200 px/s (始终世界Y轴向上)

球向下摆时: footVel.y ≈ +2000, 减200 → vel_.y ≈ +1800 (仍然向下)
球向上摆时: footVel.y ≈ -1800, 减200 → vel_.y ≈ -2000 (飞得更远)
```

### 核心矛盾

JUMP_BOOST(200) 是绝对值，footVel 是变量(0~2000+)。当 footVel ≫ JUMP_BOOST 时，跳跃对速度的修正量在视觉上不可感知。

### 可选方向

| 方向 | 做法 | 优劣 |
|------|------|------|
| A | 加大 JUMP_BOOST 到 400~600 | 简单粗暴，低速时可能跳太高 |
| B | 保证脱离速度最小值：`if (vel_.y > -200) vel_.y = -200` | 确保任何时候都有可见向上分量 |
| C | 跳跃方向随表面斜度混合（球面法线 + 世界Y轴） | 物理正确，但球侧面时可能反直觉 |
| D | 不管，200 足够脱离，考验操作时机 | 设计选择问题 |

**当前状态**：不处理，等更多测试反馈后决定。

## 二、球面角度脱落边界敏感

### 现象

安全区 `t ∈ [0.01, 0.99]`，snap 落点 margin 为 0.03。在极端摆动下，角色可能频繁在安全区和脱落区之间震荡。

### 当前缓解

- snap 后 t 钳制到 `[0.03, 0.97]`
- 跳跃保护 15 帧 (FLY_GRACE_FRAMES)

### 待观察

是否需要加入「刚被角度脱落过的球面」短时锁定（如 30 帧内不对同一球再次脱落）。
